# Qurʼān Parho Framework (قرآن پڑھو فریم ورک)

A community project by **Maulana Syed Imon Rizvi (مولانا سیّد آئمن رضوی)**.

A practical, low-friction blueprint for launching neighborhood Qurʼān understanding circles.

## Development

```sh
npm install
npm run dev
```

## Tech Stack

- React 19 + TanStack Start + Vite
- Tailwind CSS v4
- shadcn/ui components
- Deployed on Vercel
