# Recording Checklist — Urdu Tutorial Video Series

Use this before and during every recording so all 7 videos look and sound consistent.

## Before you record (every video)
- [ ] Clean browser profile: use a fresh/incognito window so no leftover highlights, searches, or saved settings appear on screen.
- [ ] Site is the LIVE one: `https://quran-parho.vercel.app` (not `localhost`).
- [ ] Zoom set so the whole relevant section fits; text is legible.
- [ ] Sound check: recording mic ~30cm away, no fan/AC noise. Do a 10s test take and play it back.
- [ ] Recitation/audio clips are short (≤10s) so they never overlap the narration.
- [ ] Screen recorder set to 1080p, 30fps, and the exact section of the screen you'll narrate.

## During the take
- [ ] Urdu narration at a calm, teaching pace; 3s pause on each new screen before speaking.
- [ ] Mouse cursor moves slowly and points at the exact button being named.
- [ ] No personal data on screen (real names in Round-Robin / notes are replaced with examples).
- [ ] Never speak while Quranic audio is playing.
- [ ] If a live action fails (search returns nothing, QR won't pair), stop, reset, and retake that scene — don't narrate over a broken demo.

## After each take
- [ ] Watch through with sound; check Urdu spelling on any on-screen text.
- [ ] No background tabs, no notifications, no browser bookmarks bar visible.
- [ ] Render at 1080p; keep file naming `quran-parho-01-intro.mp4` … `quran-parho-07-sharing.mp4`.
