# Video 6 — Facilitator Tools + Phone Remote

**Target length:** ~6 min
**Prerequisite:** Video 5.

---

## Scene 1 — Tools overview (0:00–0:50)

**On screen:** Scroll to the "Tools" section on the homepage. Show the 8 tool cards.

**Narrator (Urdu):**
آج کا موضوع ہے: فسیلیٹیٹر کٹ — یعنی محفل چلانے والے کے لیے **8 ٹولز**۔ سیشن ٹائمر، باری ٹریکر، سوال ٹائمر، مراحل کی پیش رفت، رفتار کیلکولیٹر، سورہ کوئز، کیلنڈر، اور ڈیش بورڈ۔ آج ہم پہلے چار ٹولز اور فون ریموٹ دیکھیں گے، اور اگلی ویڈیو میں بقیہ چار کو تفصیل سے۔

یہ ٹولز اسی جگہ کھلتے ہیں جہاں آپ ریڈر چلاتے ہیں — یعنی ایک ہی سکرین پر پڑھنا بھی اور محفل کا انتظام بھی۔

**Action:** Scroll to Tools. Pan across the 8 cards slowly.

---

## Scene 2 — Session Timer (0:50–1:50)

**On screen:** Open "Session Timer". Set a duration. Start it. Show the countdown.

**Narrator (Urdu):**
**سیشن ٹائمر** محفل کا وقت مقرر کرتا ہے — مثلاً 45 منٹ۔ شروع کریں تو گنتی نیچے آتی ہے، اور ختم ہونے پر اطلاع ملتی ہے۔ یہ اس بات کو یقینی بناتا ہے کہ محفل اپنے وقت پر ختم ہو — خاص کر جب بحث کہیں اور بھٹکنے لگے۔

فسیلیٹیٹر کے لیے یہ سب سے ضروری ٹول ہے، کیونکہ اچھی محفل وہی ہے جو وقت کی پابندی کرے۔

**Action:** Open Session Timer → pick 5:00 → Start → show countdown running 5 seconds → Stop.

---

## Scene 3 — Round-Robin (bari tracker) (1:50–2:40)

**On screen:** Open "Round-Robin". Show the members list and the turn indicator.

**Narrator (Urdu):**
**باری ٹریکر** ریکارڈ رکھتا ہے کہ اس ہفتے تلاوت کس کی باری ہے۔ اراکین کے نام ڈالیں، اور جو پڑھ چکا اس کے ساتھ نشان لگائیں — اگلی باری خود آگے بڑھتی ہے۔ اس سے کوئی پیچھے نہیں رہتا اور کوئی دو بار نہیں پڑھتا۔

یہ ہمارے ٹرن بار سے جڑا ہوا ہے جسے ہم نے پچھلی ویڈیو میں دیکھا تھا۔

**Action:** Open Round-Robin → add 3 names → mark one as read → show turn move to next.

---

## Scene 4 — Q&A Timer (2:40–3:30)

**On screen:** Open "Q&A Timer". Start a question round; show the count-up or count-down per speaker.

**Narrator (Urdu):**
**سوال ٹائمر** بحث کے دوران ہر سوال اور جواب کے لیے وقت مقرر کرتا ہے — مثلاً ہر سوال کے لیے 2 منٹ، ہر جواب کے لیے 3 منٹ۔ اس سے بحث منظم رہتی ہے اور ہر ایک کو برابر موقع ملتا ہے۔

یہ خاص طور پر ان محفلوں کے لیے ہے جہاں خاموش اراکین ہوں یا گفتگو پر ایک دو لوگ حاوی ہوں۔

**Action:** Open Q&A Timer → set 2:00 for Q, 3:00 for A → Start Q timer → show countdown.

---

## Scene 5 — Cycle Progress (3:30–4:10)

**On screen:** Open "Cycle Progress". Show the 3 cycles and the progress bar per cycle.

**Narrator (Urdu):**
**مراحل کی پیش رفت** آپ کو بتاتی ہے کہ تینوں مراحل — سمجھ، حفاظ، عمل — میں سے ہر ایک میں آپ کا حلقہ کس حد تک پہنچا ہے۔ یہ محفل کی رفتار کا تصویر بن جاتا ہے: کتنی آیات سمجھی گئیں، کتنی حفظ کی گئیں، کتنا عمل ہوا۔

یہ ڈیش بورڈ کی بنیاد ہے، جسے ہم اگلی ویڈیو میں تفصیل سے دیکھیں گے۔

**Action:** Open Cycle Progress → point at each of the 3 progress bars.

---

## Scene 6 — Phone remote (4:10–5:40)

**On screen:** Open the timers screen → click the remote button → the pairing panel with a QR code and a room code appears. Then show a phone connected as a member.

**Narrator (Urdu):**
اور اب سب سے دلچسپ ٹول: **فون ریموٹ**۔ فرض کریں آپ پروجیکٹر پر ٹائمر چلا رہے ہیں، لیکن آپ اپنی جگہ سے اٹھے بغیر اسے کنٹرول کرنا چاہتے ہیں — یا آپ چاہتے ہیں کہ کوئی دوسرا رکن ٹائمر شروع یا بند کرے۔ اس کے لیے "ریموٹ" کا بٹن کھولیں۔ اسکرین پر ایک **QR کوڈ** اور **روم کوڈ** آتا ہے۔

اپنے فون پر quran-parho.vercel.app/remote کھولیں — یا سیدھا QR اسکین کریں — اور روم کوڈ ڈال دیں۔ فون اب اسکرین سے جڑ گیا۔ اب آپ فون سے ہی ٹائمر شروع کر سکتے ہیں، روک سکتے ہیں، اور سیشن کی حالت دیکھ سکتے ہیں — جبکہ بڑی اسکرین سامعین کو دکھائی دیتی رہتی ہے۔

اس کے لیے آپ کا فون اور کمپیوٹر ایک ہی انٹرنیٹ سے جڑے ہونے کی ضرورت نہیں — ریموٹ انٹرنیٹ پر کام کرتا ہے۔

**Action:** Open remote panel → show QR + room code. Record a phone screen side-by-side: scan QR (or type code) → press "Start" on the phone → the big-screen timer starts → press "Pause" on phone. Narrate over the phone action.

---

## Scene 7 — What's next (5:40–6:00)

**On screen:** End card.

**Narrator (Urdu):**
یہ تھے فسیلیٹیٹر کے اہم لائیو ٹولز اور فون ریموٹ۔ اگلی — اور آخری — ویڈیو میں ہم رفتار کیلکولیٹر، کیلنڈر، کوئز اور ڈیش بورڈ دیکھیں گے، اور سیکھیں گے کہ اس ویب سائٹ کو اپنی محفل میں کیسے شیئر کریں۔ اللہ حافظ!

**Action:** Fade out.

---

### Timing / pause notes
- Total ~6:00.
- Phone remote is the highlight: record the phone screen with a capture app (or a second device). Practice the pairing once BEFORE the take so the QR/code demo is smooth.
- All timers: use 2–5 minute values on screen so countdowns visibly tick without making the video long.
